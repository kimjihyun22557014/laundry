# 입고, 남은 것들

소재 표본 카드로 보는 1–10일차 옷장 아카이브입니다.

사이트 주소: https://kimjihyun22557014.github.io/laundry/

## 보기

- 카드 아래 01–10 번호에 커서를 대거나 클릭하면 해당 날짜가 정면에 표시됩니다.
- 스크롤 또는 방향키로 날짜순으로 이동합니다. Home/End는 처음/마지막으로 이동합니다.
- 링을 누른 채 원형으로 움직이면 종이들이 360도로 펼쳐집니다. 놓으면 읽던 카드로 돌아옵니다.
- 커서를 카드 위로 움직이는 것만으로는 회전하거나 선택이 바뀌지 않습니다.

## 수정할 파일

- index.html: 사이트의 기본 진입 파일
- app.js: 카드 표시와 탐색 동작
- style.css: 화면 디자인
- data.js: 날짜별 사진과 브랜드, 색상, 소재, 기록
- assets/: 사진 10장

텍스트는 data.js에서 수정합니다. 사진 경로는 assets/day-01.jpg처럼 상대경로를 사용합니다.

기본 사이트 주소에는 정확히 index.html이라는 이름의 파일이 사용됩니다. index .html(공백 포함)과 index 2.html은 기본 주소에 적용되지 않는 이전 파일입니다.

외부 라이브러리나 별도 빌드 없이 GitHub Pages에서 실행됩니다.
