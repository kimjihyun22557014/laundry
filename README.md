# 입고, 남은 것들

검은 화면 중앙에 링으로 묶인 소재 표본 카드만 놓인 옷장 아카이브입니다.
사진 10장과 실행에 필요한 파일을 포함하며 설치 없이 index.html을 브라우저로 열 수 있습니다.

## 카드 고르기

- 커서를 묶음 가까이 가져가면 카드가 부채처럼 펼쳐집니다.
- 원하는 카드 위에 커서를 올리면 그 카드가 살짝 튀어나옵니다.
- 링을 중심으로 커서를 원형으로 움직이면 표본들이 차례로 넘어갑니다.
- 묶음에서 커서를 멀리 빼면 다시 모입니다.
- 터치 화면에서는 손가락으로 링 주변을 원형으로 움직입니다.
- 방향키로 카드를 고르고 Escape로 묶음을 접을 수 있습니다.

## 텍스트 넣기

data.js에서 각 날짜의 brand(브랜드), color(색), material(소재), note(기록)를 수정하세요. 현재 이 항목들은 최종 문구를 넣을 수 있도록 비워두었습니다. 카드 밖에는 제목이나 설명을 표시하지 않습니다. tags는 이번 화면에서는 사용하지 않습니다.

## 표본 추가

assets 폴더에 새 이미지를 넣고 data.js의 items 배열에 같은 형식의 항목을 추가하세요. 각 항목은 쉼표로 구분합니다. 예를 들어 11일차는 day: 11, image: "assets/day-11.jpg"로 지정합니다.

사진은 원본과 별도로 웹용 JPEG로 최적화했습니다.

## GitHub Pages

이 폴더 안의 파일과 assets 폴더를 저장소 루트에 업로드하세요. ZIP 자체를 업로드하지 마세요. 저장소의 Pages 설정에서 배포할 브랜치와 루트 폴더를 선택하면 됩니다. 모든 경로는 상대경로이며 외부 라이브러리나 API 키가 필요하지 않습니다.
