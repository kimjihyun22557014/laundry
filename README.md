# 입고, 남은 것들

사진 표본을 날짜순으로 읽는 아카이브입니다.

사이트: https://kimjihyun22557014.github.io/laundry/

- 평소에는 카드 묶음과 현재 날짜 / 전체 개수만 표시합니다.
- 카드에 커서를 올리면 살짝 펼쳐집니다. 커서 움직임으로 회전하지 않습니다.
- 카드 아래 오른쪽 모서리에 커서를 대면 종이가 말리고, 누르면 다음 날짜로 넘어갑니다. 왼쪽 모서리는 이전 날짜입니다. 첫/마지막에서는 더 넘어가지 않습니다.
- 스크롤 한 동작에 한 장씩 이동합니다. 방향키, Page Up/Down, Home/End도 지원합니다.
- 모바일에서는 카드를 좌우로 밀어 넘깁니다.
- 날짜 표시를 누르면 사진 목록에서 원하는 날짜로 바로 이동할 수 있습니다.

## 30일차까지 추가하기

data.js의 items 배열에 day, image, brand, color, material, note 항목을 추가합니다.
사진은 assets에 넣고 image에 상대경로를 적습니다. 날짜순 정렬, 전체 개수, 사진 목록은 자동 반영됩니다.
등록되지 않은 날짜의 사진은 만들거나 복제하지 않습니다. 현재 10장 등록 상태에서는 01 / 10으로 표시하고, 30장 등록 후에는 01 / 30으로 표시합니다.

기본 진입 파일은 정확히 index.html입니다. index .html과 index 2.html은 이전 수정본이며 기본 사이트에는 쓰이지 않습니다.
