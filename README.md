# 입고, 남은 것들

링으로 묶은 소재 표본 카드에서 착안한 개인 옷장 아카이브입니다.
첨부한 1~10일차 사진을 포함한 HTML/CSS/JavaScript 사이트로, 설치나 빌드 없이 실행할 수 있습니다.

## 먼저 보기

`index.html`을 브라우저로 여세요. 사진 클릭으로 확대, 이전/다음 표본, 방향키, 모바일 좌우 스와이프, 전체 펼치기를 사용할 수 있습니다.

## GitHub Pages에 올리기

1. GitHub 저장소를 만들고 이 폴더 **안의 파일과 assets 폴더**를 모두 저장소 루트에 올립니다. ZIP 자체를 올리지 마세요.
2. 저장소의 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
3. main 브랜치, /(root)를 선택하고 Save를 누릅니다.
4. 배포가 완료되면 Pages에 표시되는 주소로 접속합니다.

모든 경로는 상대경로이므로 저장소 이름이 붙는 GitHub Pages 주소에서도 동작합니다. 외부 라이브러리, API 키, 서버, 유료 서비스는 필요 없습니다.

## 텍스트 넣기

`data.js`에서 해당 날짜의 내용을 수정하세요.

```js
{
  "day": 1,
  "image": "assets/day-01.jpg",
  "brand": "브랜드명",
  "color": "초록색, 빨간색",
  "material": "라벨로 확인한 소재",
  "note": "촉감과 개인적인 이야기를 적습니다.\n줄바꿈도 가능합니다.",
  "tags": ["color", "warm"]
}
```

- color: 컬러 강조
- scent: 향기 보유
- easy: 생각 금지
- worn: 낡음 주의
- warm: 보온 강화

분류는 아직 임의로 배정하지 않았습니다. `tags`에 해당 기호를 넣으면 분류 버튼에 반영됩니다. 여러 기호를 함께 넣을 수 있으며, 버튼은 한 번에 한 기호로 필터링합니다.

나중에 보내주실 최종 텍스트를 넣을 수 있도록 현재 브랜드/색/소재/촉감은 빈칸으로 두었습니다. 확정하지 않은 소재 정보를 사실처럼 넣지 않았습니다. 사이트 제목과 짧은 소개도 `data.js`에서 바꿀 수 있습니다.

## 표본 추가

assets 폴더에 새 이미지를 추가하고 `items` 배열 끝에 같은 형식의 항목을 추가하세요. 마지막 항목 다음에는 쉼표를 넣어 항목을 구분합니다. 예: 11일차는 `day: 11`, `image: "assets/day-11.jpg"`. 숫자는 중복되지 않게 적으세요.

사진은 원본을 건드리지 않고 웹용 JPEG로 별도 최적화했습니다. 참고 이미지 자체는 사이트에 사용하지 않았습니다.
